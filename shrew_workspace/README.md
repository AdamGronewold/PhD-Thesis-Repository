# SHREW simulation snapshot

This directory is the **thesis snapshot** of the SHREW Gazebo simulation (dissertation Chapter 7 and Appendix A.2): a catkin-style **ROS Noetic** workspace intended for **Gazebo 11**. It records the URDF, plugins, terrain, and launch files as they existed when the dissertation was filed.

It is **research software from a student-led NASA Big Idea Challenge effort**, not a maintained product. As of 2026 this workspace is **not under active development** and has **not been re-tested** on current ROS or Gazebo. Use it as an archival starting point for the modeling and simulation described in the thesis, not as a supported robot stack.

Setup, launch commands, and model notes remain in the **original package READMEs**, which are left as written:

- [`src/shrew_robot/README.md`](src/shrew_robot/README.md)
- [`src/shrew_robot_fixed_joint/README.md`](src/shrew_robot_fixed_joint/README.md)
- [`src/terrain_patches/README.md`](src/terrain_patches/README.md)
